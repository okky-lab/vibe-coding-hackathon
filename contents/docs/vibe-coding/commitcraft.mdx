## 문제 정의 (Problem)

바이브 코딩/해카톤 환경에서는 기능 구현 속도는 빨라졌지만, 무엇을 왜 만들었는지(SPEC)와 왜 그런 선택을 했는지(ADR)가 제때 정리되지 않아 커뮤니케이션·인수인계·품질 검증·발표 스토리에서 병목이 발생합니다. 결국 문서는 늦게/대충 작성되거나 누락되고, 변경 근거(커밋·diff)와 문서 내용이 불일치해 **완성도와 설득력이 떨어지는 문제**가 반복됩니다.

## 해결 방식 (Solution)

CommitCraft는 공개 GitHub 저장소의 커밋/변경(diff)을 수집하고, Lovable AI Gateway(Gemini) 기반 다단계 문서 생성 파이프라인으로 SPEC/ADR/데모 스크립트/체크리스트 초안을 생성합니다. Session + Artifacts 모델로 결과물을 저장해 반복 편집과 Export를 지원하며, 소스 근거 기반 생성 원칙을 적용해 근거 불충분 항목은 Assumptions로 분리해 문서 신뢰도를 높입니다.

## 한 줄 소개

CommitCraft는 GitHub 커밋/변경(diff)을 근거로 [SPEC.md](http://spec.md/)·[ADR.md](http://adr.md/)·데모 스크립트·체크리스트를 자동 생성하고, 편집/Export까지 지원하는 DocOps LLM 에이전트입니다.

## 데모 설명 (3분 이내 기준)

공개 저장소 URL을 입력하면 커밋·diff를 분석해 제출용 문서 세트를 자동 생성하고, 결과를 즉시 검토/편집/내보내기 할 수 있습니다.

## 팀 소개 및 역할

- 홍유석: 바이브코더 및 딸깍
- 이지은: 기획 및 딸깍

## 기술 스택

- Lovable AI (Builder)
- Lovable Cloud (PostgreSQL, Edge Functions, Secrets)
- Lovable AI Gateway (Gemini)
- GitHub API

## 실행/검증 방법

1. https://commitcraft.kro.kr/ 접속
2. 공개 GitHub 저장소 URL 입력
3. 문서 생성 실행
4. 생성된 SPEC/ADR/데모/체크리스트와 Assumptions 섹션 확인
