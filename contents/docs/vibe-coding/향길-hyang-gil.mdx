## 문제 정의 (Problem)

장례식장에서 음식 주문이 수기로 전달되어 30% 오류 발생. 문자로 주소만 전달되어 조문객이 길을 못 찾는 문제.

## 해결 방식 (Solution)

핵심 구현 아이디어와 접근 방식을 정리했습니다.

## 한 줄 소개

QR 하나로 주방 발주와 조문객 안내를 디지털화하는 장례식장 협업 플랫폼

## 데모 설명 (3분 이내 기준)

QR 스캔 → 조문객 안내 페이지, 상주 대시보드에서 실시간 주문 관리, 주방 대시보드에서 Supabase Realtime 구독으로 실시간 발주 확인

## 팀 소개 및 역할

- YeoulHi: 풀스택 (FE/BE/기획/디자인)

## 기술 스택

Next.js 15, TypeScript, Supabase (PostgreSQL + Realtime), Tailwind CSS 4, Vercel
