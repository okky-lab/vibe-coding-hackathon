### AuraGC

- 한 줄 소개: Infrastructure-aware proactive memory governor for Python 3.14
- 해결하려는 문제: Python's default GC is reactive and often leads to OOM kills in memory-constrained containers (512MB). AuraGC provides a proactive, 3-tiered defense using Linux PSI to ensure survival and stability under extreme memory pressure.
- 팀 구성:
- juwonkim: Core Engine & Visualizer
- Antigravity: AI Coding Assistant
